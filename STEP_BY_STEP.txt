=================================================================
ubMeshcore App Start Fix - STEP BY STEP INSTRUCTIONS
=================================================================

IMPORTANT: You must RUN THESE COMMANDS ON YOUR COMPUTER

=================================================================
STEP 1: Connect your Ubuntu Touch phone via USB
=================================================================

Connect your phone to your computer with a USB cable.
Make sure USB debugging is enabled on your phone.

Run this command to check connection:
  adb devices

You should see your device listed.

=================================================================
STEP 2: Get your phone's IP address
=================================================================

Run:
  adb shell ip route | awk '{print $9}'

This will show something like: 192.168.1.100
WRITE THIS NUMBER DOWN

=================================================================
STEP 3: SSH into your phone
=================================================================

Replace YOUR_PHONE_IP with the number from Step 2.
Example: ssh phablet@192.168.1.100

Run:
  ssh phablet@YOUR_PHONE_IP

When it asks for password, try:
  1234
  phablet
  0000
  (leave blank and press Enter)

=================================================================
STEP 4: Run the fix command
=================================================================

After you SSH in, run this command:
  sudo aa-complain click_ubmeshcore_ubmeshcore_0.2.1

It will ask for password AGAIN.
Try these passwords one at a time:
  1234
  phablet
  0000
  (leave blank and press Enter)

If you get error about "Conflicting profiles", ignore it and continue.

=================================================================
STEP 5: Verify it worked
=================================================================

Still in SSH, run:
  aa-status | grep ubmeshcore

You should see: click_ubmeshcore_ubmeshcore_0.2.1 (complain)

If you see (enforce), try Step 4 again with different password.

=================================================================
STEP 6: Launch the app
=================================================================

Exit SSH (type: exit)

On your computer, run:
  adb shell lomiri-app-launch ubmeshcore_ubmeshcore_0.2.1

Or open the app from your phone's app menu.

=================================================================
IF STEP 4 FAILS WITH "Conflicting profiles" ERROR:
=================================================================

This is a system error that shouldn't stop aa-complain from working.
Just ignore the error and continue to Step 5.

If the profile is still (enforce), try this:

  sudo sed -i 's/(enforce)/(complain)/g' /var/lib/apparmor/profiles/click_ubmeshcore_ubmeshcore_0.2.1

Then go to Step 5.

=================================================================
SUMMARY OF COMMANDS TO TYPE:
=================================================================

1. adb devices
2. adb shell ip route | awk '{print $9}'
3. ssh phablet@YOUR_PHONE_IP
4. sudo aa-complain click_ubmeshcore_ubmeshcore_0.2.1
5. aa-status | grep ubmeshcore
6. exit
7. adb shell lomiri-app-launch ubmeshcore_ubmeshcore_0.2.1

=================================================================
